# Specs of my ThinkPad E450

### Basic Information
* **RAM:** 4 GB DDR3L
* **CPU:** Intel Core i5 5th Gen (Broadwell)
* **iGPU:** Intel HD 5500
* **Storage:** 256 GB SSD

---

### Detailed Information
* **Ethernet:** Intel Ethernet Connection (3) 1218-V
* **Wi-Fi/Bluetooth:** Intel Dual Band Wireless-AC 7265 (Stone Peak)
* **Audio:** Intel Wildcat Point-LP High Definition Audio

### Installation Notes
* **OS Version:** macOS 12 (Monterey)
* **Installer:** Recommended to use the **UnPlugged offline installer**. 
* **Important Tip:** Avoid the online recovery installer. It frequently gets stuck at *"2 hours and 19 minutes remaining"*, which happened during my own setup.

---

### EFI Details
* This is the **raw EFI folder** that successfully works for my system configuration.
* **Troubleshooting:** The uploaded files are the **debug version**. If the system fails to boot or encounters an error, it will generate a detailed log file to show exactly what went wrong. You can use this log to adjust the config file to match your specific hardware.
